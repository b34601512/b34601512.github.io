# 博客文章怎么加（给钟灵）

把写好的 `.md` 放进这个文件夹、在 `slugs.json` 里登记一行，就能发出去。不用改任何代码。

## 文件夹里有什么

```text
content/blog/
├─ README.md        本说明（不会被发布）
├─ slugs.json       登记表：哪个 md 发布、发布到哪个网址
└─ NN-标题.md       文章原稿，一篇一个文件
```

发布后的网址：

- 列表页：`https://luyao2089.cc/blog/`
- 文章页：`https://luyao2089.cc/blog/<slug>/`

## 加一篇文章：4 步

1. 把文章存成 `NN-标题.md` 放进 `content/blog/`（比如 `08-拼多多客服考核.md`）。
2. 在 `slugs.json` 里加一行「文件名 → slug」。slug 就是网址里那一段，只能用**小写英文、数字和连字符**，比如：

   ```json
   {
     "07-淘宝响应时长考核-盯哪些指标不漏项.md": "taobao-response-time-metrics",
     "08-拼多多客服考核.md": "pdd-service-metrics"
   }
   ```

   注意上一行末尾要补逗号。slug 发出去以后别再改，改了旧网址就失效了。
3. 在网站目录里运行：

   ```powershell
   node scripts/build-site.mjs
   node scripts/check-site.mjs
   ```

   第二条最后一行是「自检通过」才算成功。
4. 提交（commit）并推送。

没在 `slugs.json` 里登记的 md 不会发布（构建时会提示一句「没有登记，跳过」），所以没写完的稿子放在这里也没关系。

## 文章开头的格式（必须照这个写）

```markdown
# 文章标题

> 2026-10-18 · 推广专员·钟灵（…）
> 渠道：…
> **状态：…**
> 写法依据：…

---

## 结论先说
正文……
```

- 第一行 `# 文章标题` 就是网页标题，全文只能有这一个 `#`。
- 日期取「第一条以 `> 年-月-日` 开头的行」，写成 `2026-10-18` 这种格式。
- **从 `#` 标题到第一条单独一行的 `---` 之间，全部是内部备注，一个字都不会发布。** 渠道、状态、写法依据、事实依据、跟别的稿子的分工，都可以放心写在这里。
- 正文从第一条 `---` 之后开始。
- 列表页卡片上的一句话摘要：默认取正文第一段（跳过标题、表格、列表、引用），超过 80 字会在句读处截断。想自己写摘要，就在备注区加一行 `> 摘要：……`。

## 文末的内部区：「发布前检查」

正文里**第一个文字里含「发布前检查」的小标题**（`## ` 或 `### `，比如 `## 七、发布前检查（自查，发布时删掉）`）是内部区的开始：**这个小标题和它后面的所有内容都不会发布**，网页正文停在它前面一节。自查表、待核事实、产品事实核对记录都可以放心写在这里，不用发布前手动删。构建时会提示一句「跳过内部区：文件名（发布前检查起 N 处）」。

所以内部区一定要放在**文末**：「发布前检查」小标题后面再写的正文，也一并不会发布。除了备注区和这块内部区，其余内容都会原样发布。

## 支持的写法

- 小标题：`## ` 和 `### `（正文里写 `# ` 或 `#### ` 会让构建直接报错）
- 段落：段与段之间空一行；段内换行会变成一个空格
- 列表：`- ` 无序列表、`1. ` 有序列表（只支持一层，编号按你写的显示）
- 引用：每行以 `> ` 开头，可以多行，里面可以加粗；引平台原文时用它，网页上会显示成带橙色竖线的引用块
- 表格：`| 表头 | 表头 |` + `|---|---|` + 内容行；宽表格在手机上会在框里横向滑动
- 行内：`**粗体**`、`` `代码` ``、`[文字](网址)`、`*斜体*`
- 单独一行的 `---` / `***`：当分节线用，网页上不显示

**不支持**：多层（嵌套）列表、脚注、HTML 代码。图片 `![说明](地址)` 只会原样输出一张图，不会帮你上传或加图注，图片文件要自己放到网站里。

## 文章顺序与上一篇 / 下一篇

- 列表页按日期从新到旧排；同一天的按文件名排（`01-` 在 `03-` 前面）。
- 文章页底部的「上一篇」是列表里排在它**上面**的那篇（更新的），「下一篇」是排在它**下面**的那篇（更早的）。

## 其他

- 每篇文章的「修改日期」暂时等于发布日期（原稿只有一个日期）。改了已发布的文章，日期不会自动变。
- sitemap（给搜索引擎的网址清单）会自动加上新文章，不用手改。
