# 官网短片、主题与视觉规范

> 只在修改 guide 短片、主题或通用视觉时读取。

## 设计规范

### 「怎么用」演示短片（guide.html）

- 45 秒自动播放，五段对应五个步骤：分类 → 双击贴入 → 纸飞机直发 → Alt+Q 搜索 + Tab 数字发送 → 吸附搜索栏；前后各有片头片尾。页面下方的五个文字步骤就是章节按钮（`data-chapter` = `SCENES` 段号），点哪步跳到哪段。改剧本时两边一起改。
- 画面要像真软件在跑（作者嫌原先的手绘粉笔版「不够写实、看不太懂」）：舞台是 DOM，不是画布。聊天窗、话术精灵主界面、吸附搜索栏用 `guide-film.css` 里的 `gf-*` 类，尺寸照抄 `demo.css`；主界面与吸附栏配色是客户端白色主题，两种网站主题下不变；不要直接引 `demo.css`，也不要改首页演示的类。舞台底色、字幕、按键提示、标注用网站变量，跟着主题走。
- 短片里的聊天窗**画成客户天天用的平台工作台的仿真简易版**（千牛 / 京东 / 拼多多 / 抖店……，老板 2026-10-29 定）：不仿真观众认不出这是什么。形似即可，四条硬规则不能破（这正是它不侵权的原因）：① 文字里**不出现任何平台名称**；② **不画平台 logo、标志或图标**；③ **不含真实用户信息**——顾客昵称、头像、店铺名、订单号等一律用假名或打码灰条；④ 只做**简化的形似版**，不做像素级复刻、不贴别家界面截图（截图不进仓库）。平台配色可以照着画；我们自己发出的气泡和发送键仍是品牌橙 `--accent` + 白字。「怎么用」短片目前还是通用简化聊天窗（标题「顾客·小陈 / 在线」），按本规则可以改成平台形似版。
- 搜索结果卡必须整行显示三条命中（结果态行距收紧，`.gf-app-tree--results`）；按键提示是小键帽，第④段放在主界面右侧空白、与搜索框齐平，不压文字、卡片边框和搜索框。
- 舞台按 800×450 设计、`transform` 缩放到容器；舞台窄于 560px 时镜头推近 1.5 倍、按 `CAMERA` 关键帧跟着操作走，否则手机上字太小。
- 所有状态都是时间 T 的纯函数（窗口、气泡、输入框文字、鼠标、悬停、涟漪、键帽），拖到哪一秒都能还原同一帧。鼠标轨迹写目标元素的 `data-ref`，位置每帧现量，所以窗口在动时也停在按钮正中；悬停高亮按鼠标尖是否落在 `[data-hov]` 元素里算。打字每字 60–110ms（固定伪随机）。
- 聊天窗可换成真实截图：把图放进 `assets/img/`，在 `src/site/pages/guide.mjs` 的 `filmShots.chat` 填路径，舞台带上 `data-chat-shot`，聊天窗切到 `data-skin="shot"`（代码画的外框隐藏，气泡与输入框文字照常叠在上面）。
- 只在进入视野（≥35%）且标签页可见时播放；访客自己按了暂停就不再自动续播。`prefers-reduced-motion` 时不自动播，停在 16.8 秒那一帧。**headless Chrome 默认报 reduce**，探针要先 `Emulation.setEmulatedMedia` 设成 `no-preference`，否则会以为动画没播。
- 文案必须和客户端一致（双击只贴不发、纸飞机＝贴入 + 回车、Tab 后数字直接发送、吸附栏不用切回主界面），与首页演示同一套事实。

### 竖屏短片的翻页过渡（freight / why / diff，issue #18）

- 换到**不相干的画面**时用早期 iOS 那种推页：新画面从右边整页推进来，旧画面往左退得慢一些（视差）、同时压暗，两页交界一道阴影；不转、不缩放、不淡。同一段操作里的镜头推拉、话术精灵滑进滑出**不是**翻页。
- 实现只有一份：`assets/js/film-page-turn.js`。它**不改** `film-engine.js`（老板定：过渡单独做一个引擎），自己把片子画两遍（旧页定格在原快切开始前一帧、新页从快切结束处往下走），各自走镜头与 overlay，再画阴影。片子只登记每次翻页的 `{ from, to }`（就是原来 0.12 秒快切的头和尾），片长不变。
- 字幕和镜头外那一层跟着各自那一页走。手感参数（时长、视差、压暗、阴影）都在模块顶上。

### 白天 / 黑夜主题

- 默认**跟随系统**（`prefers-color-scheme`）：系统明确是深色才用黑夜，其余情况（浅色、没设置、读不到、没开 JS）一律白天。导航右侧圆形按钮手动切换，选择存在 `localStorage` 的 `softtalk-theme`；手动选过以后就不再跟系统。没选过时页面开着也会跟着系统实时切换（`theme.js` 监听 `matchMedia` 的 change）。
- `<html data-theme="light">` 是静态默认值；`layout.mjs` 在 head 里用一行内联脚本在首屏绘制前按「手动选择 → 系统深色」改成 `dark`，避免闪白。`theme.js`（defer）只管按钮、文案、`theme-color` 和系统变化。
- 两套颜色都只在 `site.css` 顶部的 `[data-theme="dark"]` / `[data-theme="light"]` 变量里定义，组件里不写死颜色；新增颜色要两套都给值。白天的橙压深为 `#c2410c`，保证小字 4.5:1。
- 演示区只有平台标签卡（在网站背景上）跟着主题变；聊天窗与话术精灵主界面是客户端复刻，两种主题下保持原样。
- 支持 View Transitions 的浏览器从按钮位置圆形铺开新主题；`prefers-reduced-motion`、不支持、或过渡被浏览器 abort（`ready` reject）时退化为 140ms 淡入（`theme.js` 的 `pickMotion` 判据）。自检页 `check-motion.html`（`extraPages`，noindex）能看偏好、支持情况和一次真实切换的 ready 结果。

下表是黑夜主题的值（白天的值见 `site.css`）：

| 变量                           | 值                                 | 用途                                    |
| ---------------------------- | --------------------------------- | ------------------------------------- |
| `--bg`                       | `#000`                            | 页面背景，纯黑                               |
| `--surface` / `--surface-2`  | `#0d0c0b` / `#1a1815`             | 面板与控件底色（微暖，和纯黑背景拉开层次）                 |
| `--fg`                       | `#f5f5f5`                         | 主文字                                   |
| `--fg-muted` / `--fg-dim`    | `#b8b8b8` / `#8c8c8c`             | 次级文字、说明与占位（小字提示必须 ≥ `--fg-dim`，否则看不清） |
| `--line` / `--line-strong`   | `#262626` / `#3f3f3f`             | 细线分隔、可交互描边                            |
| `--accent` / `--accent-soft` | `#ff6b2c` / `rgba(255,107,44,.1)` | 品牌橙：标题高亮、小标签、主按钮底、选中态、焦点圈、价格推荐档       |
| `--ok`                       | `#3ddc84`                         | 仅用于状态点（客户端演示区的在线绿点）                   |
| `--width`                    | `1000px`                          | 内容最大宽度                                |
| `--mono`                     | 系统等宽字体                            | 价格、编号、套号                              |

约定：

- 主按钮是「橙底 + `--on-accent` 字」（`.btn--primary`，黑夜黑字、白天白字），次级按钮是细描边（`.btn--ghost`，hover 变橙描边橙字）。
- 首页首屏下方直接是可交互演示（主界面 + 聊天窗口 + 底部吸附栏），之后就是页脚（不再有「三步用起来」、截图、功能卡与常见问题）。加内容优先往演示区里做，不要再往首屏下塞过渡性小节或复述型文案。
- 区块用 `.section`（顶部 1px 细线 + 上下留白）分隔，内容包在 `.wrap` 里；区块标题上方有一道橙色短线（`.section h2::before`）。
- 正文以白/浅灰为主，橙色只做强调：小标签、标题关键词、选中态、按钮；不要用它铺大面积色块。
- 正文里的小字提示（如「点击复制」）用橙色，比灰色更容易看见。
- 首页演示（`demo.css` + `demo.js`）的类名、元素 ID 是一套契约：改一边必须改另一边；`check-site.mjs` 会拦住不一致。
- 动效只用一次性的轻微上浮（`@keyframes rise`）与消息入场（`@keyframes msg-in`），并尊重 `prefers-reduced-motion`。
